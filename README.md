# 🎬 EvilShtrib-Highlights

Автоматизированный пайплайн поиска красивых моментов (хайлайтов) в демозаписях сервера **Counter-Strike 1.6 Biohazard (EvilShtrib)** и их рендеринга в формат **MP4 (1280x720 HD, 30 FPS)**.

---

## 🚀 Возможности и Архитектура

1. **Парсинг сетевых кадров GoldSource Protocol 48:**
   - Чтение структуры директорий и потока пакетов демо-файлов `.dem`.
   - Точный перехват игровых событий `DeathMsg` (ID 83) с определением убийцы, жертвы, оружия и статуса попадания в голову (Headshot).
   - Исключение событий заражения (`infection`) и фокусировка на эффектных уничтожениях зомби людьми.

2. **Интеллектуальная кластеризация и скоринг хайлайтов:**
   - Алгоритм объединяет последовательные фраги одного игрока в динамические окна **от 5.0 до 9.5 секунд**.
   - Система начисления очков (Score):
     - Мульти-киллы (дабл, трипл, квадро): до +150 очков.
     - Хедшоты: +35 очков.
     - Бонусы оружия: Нож (+100), AWP (+50), Граната HE (+45), Deagle (+40), Дробовики M3/XM1014 (+35), AK-47/M4A1 (+25–30).
     - Разнообразие: автоматическая фильтрация для охвата разных карт и арсенала оружия.

3. **Аппаратный рендеринг через GoldSource движок:**
   - Автоматическая генерация конфигурационных скриптов `.cfg` с командами `dem_forcehltv 1`, `viewdemo`, `dem_jump <время>`, `trackplayer <игрок>`, `startmovie <префикс> 30`.
   - Мгновенный переход к таймкоду момента в демо без необходимости ручной перемотки.
   - Сборка последовательности кадров в MP4-видеопоток высокого качества через **OpenCV (cv2.VideoWriter, кодек mp4v, 1280x720)**.

## 🛠️ Запуск пайплайна

1. **Загрузка свежих демок с игрового VDS:**
   ```bash
   python tools/download_demos.py
   ```
2. **Анализ демок и поиск лучших моментов:**
   ```bash
   python tools/analyze_highlights.py
   ```
3. **Пакетный рендеринг всех видео-клипов в MP4:**
   ```bash
   python tools/render_clips.py
   ```
